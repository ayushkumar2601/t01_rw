# Task 01 Submission — LLM Brain Prompting Architecture

This folder contains the complete deliverables for **Task 01 — LLM Brain Prompting Architecture (B2B Growth Strategy Data Report Generator)**.

## Deliverables Included

1. **`PROMPT_ARCHITECTURE.md`**
   - The complete, multi-layered prompting strategy document:
     - Layer 1: System Persona & Operational Constraints (`prompts/system.md`)
     - Layer 2: 7-Step Chain-of-Thought Procedure (`prompts/strategy_procedure.md`)
     - Layer 3: Dynamic Pydantic Output Schema Injection (`schemas/report_schema.py`)
     - Layer 4: Few-Shot Input/Output Demonstrations (`prompts/few_shot_examples.json`)
     - Layer 5: Context Injection (`data/saas_company.json`)
     - Strict Schema Enforcement (`extra="forbid"`) & Deterministic Business Rules
     - Failure Handling, Bounded Self-Correction, and Audit Logging

2. **`test_llm_brain.py` & `main.py`**
   - Python test and pipeline execution scripts used to test the LLM Brain through the Groq API.
   - Logs input and final JSON output.
   - Runs validation checks on JSON schema, types, budgets, and scoring formulas.
   - Saves the machine-readable JSON report.

3. **`sample_report.json`**
   - The exact, validated JSON output generated by the live LLM Brain from synthetic SaaS company metrics (`FlowPilot`).
   - Features:
     - Executive summary diagnosing the 8.5% churn bottleneck.
     - Exactly 3 prioritized growth channels with mathematical priority scores.
     - 30-day "Systems, not campaigns" 4-week execution roadmap with clear task owners, KPIs, and deliverables.

## How to Run

From the project root:
```bash
# Run the test pipeline script
python submission/test_llm_brain.py

# Or inspect the assembled prompt without an API call
python submission/test_llm_brain.py --print-prompt

# Or run the main pipeline
python -m src.main --input data/saas_company.json --output submission/sample_report.json
```
